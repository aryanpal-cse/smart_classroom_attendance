Attendance Verification Flow

The system does not allow face verification to bypass the temporary class code.

Step 1

Teacher Starts Class

A temporary six-character code is generated.

Step 2

Student Enters Code

The system confirms the student belongs to that class.

Step 3

Face Verification

Local OpenCV LBPH compares the live capture with registered samples.

Step 4

Attendance Result

A match records attendance; a failure can enter teacher manual review.

Face images and the trained model stay in the local face_data folder. Do not include real student images in a public repository or submission ZIP.
